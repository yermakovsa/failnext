# Security Policy

This document describes how to report security vulnerabilities in `failnext`.

## Supported Versions

Security fixes, when released, generally target the latest version of `failnext`. Backports to older versions are not guaranteed.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately through [GitHub's vulnerability reporting](https://github.com/yermakovsa/failnext/security/advisories).

Do not report security vulnerabilities through public GitHub issues or pull requests.

Include the affected version, steps to reproduce the issue, and its potential impact. Do not include real credentials or secrets.

Reports will be reviewed, and disclosure can be coordinated when appropriate.
